# HBM 供需紧张延续至下一代平台

> Thesis 状态: 🟢 active · 本文件由 DB 渲染（render --all 可重建）

## 核心假设
<!-- IAI:SECTION:hypothesis START (v1, 1) -->

HBM 供给受制于先进封装产能，需求随新一代 GPU 平台放量，供需紧张将延续，
价格与稼动率维持高位，相关封测/设备/材料公司受益。
