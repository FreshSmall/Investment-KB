# 板块学习 SOP（六步闭环）

> 学任何一个板块，本质是回答三个问题：**钱从哪来（需求）、卡在哪个环节（供给瓶颈）、用什么数据最先感知（仪表盘）**。
> 换板块 = 换这三个答案，流程不变。
> 时间预算：首次搭骨架 3~4 周，之后每周约 1 小时维护。

## 总览

| 步骤       | 动作                                     | 时间            | 产出                       |
| -------- | -------------------------------------- | ------------- | ------------------------ |
| 1 建立框架   | 读 3 篇研报（年度策略 + 产业链深度 + 海外映射）           | 第 1 周，约 3h    | 一段话说清板块逻辑 + 当前最大分歧       |
| 2 产业链地图  | 画「环节 / 龙头 / 格局 / 壁垒」表                  | 第 1~2 周，约 3h  | 一张自己画的产业链表               |
| 3 指标仪表盘  | 找 3~5 个先行指标                            | 第 2 周         | 一页"看什么数据、去哪看、多久看一次"清单    |
| 4 精读龙头财报 | 每个高壁垒环节挑 1 家龙头读 2~3 年财报                | 第 3~4 周，之后每季度 | 营收 / 毛利率 / 合同负债 / 存货四项记录 |
| 5 接入跟踪系统 | thesis seed + industry_update + weekly | 一次性配置         | 系统自动日常跟踪                 |
| 6 复盘输出   | 每周三句话                                  | 每周 30min      | 持续的板块跟踪笔记                |

## 第一步：建立框架——搞清楚"钱从哪来"

- **通用动作**：读 3 篇研报建立骨架，不读新闻（新闻是碎片，研报是地图）。
- **核心问题**：这条链的钱最终是谁花的？找到最终买单方，就找到了整条链的"总龙头"，其他环节都是它的影子。
- **检验标准**：一段话能说清板块逻辑 + 说得出当前最大的分歧点。

## 第二步：画产业链地图——上中下游 + 龙头 + 壁垒

- **通用动作**：每行一个环节，四列：环节 / 代表公司 / 竞争格局 / 壁垒高低。
- **原则**：壁垒高的环节（设备、核心零部件、专利）利润最厚，最值得深研究。
- 自己抄一遍地图比看十遍有用。
- **公司名加股价链接**：公司列中的 A 股上市公司，公司名后统一加 ` [📈](https://stockpage.10jqka.com.cn/688041/)` 形式的同花顺个股页链接（只带 6 位代码，沪深北通用）；未上市公司不加链接、注明（未上市）。笔记写完后跑 `python3 <investment-ai>/scripts/add_quote_links.py <文件>` 自动补全，输出会列出未加链接的公司名供人工核对（新上市公司先查代码再登记进脚本）。

## 第三步：建"指标仪表盘"——找到先行指标

- **通用动作**：问自己"这个板块的景气度，用什么数据能最早感知？"
- 找到仪表盘，就从"听故事"变成"看数据"。
- 指标分层：全球锚（海外龙头财报/指引）→ 国内驱动（capex/政策/订单）→ A股兑现最早的环节（季度收入/毛利率）。

## 第四步：精读龙头财报

- **通用动作**：每个高壁垒环节挑 1 家龙头，读最近 2~3 年财报，只盯四样：
  1. 营收增速
  2. 毛利率趋势
  3. 合同负债（订单先行指标）
  4. 存货
- 重点读"管理层讨论与分析"——董事长亲自告诉你行业在发生什么。
- 用机构一致预期交叉验证（覆盖机构 <3 家的预期要打折）。

## 第五步：接入跟踪系统（investment-ai）

1. `thesis seed` 把研究假设写进系统，关联地图里 3~5 家公司 → 系统每日自动采集事件、AI 分类分级。
2. `industry_update` SECTION 协议滚动维护行业长文档 → changelog 就是板块动态日志。
3. 每周日 `weekly` 周报复盘 → 检验假设被验证 / 证伪（falsified / weakened 状态）。

## 第六步：输出倒逼输入（每周 30 分钟）

每周三句话复盘：
1. 本周仪表盘指标变了什么？
2. 对应产业链哪个环节？
3. 我的假设被验证还是证伪？

写不出来 = 前面几步没做实。

## 实例一：AI 算力 / 应用（2026-09 走通的样板）

**三个问题的答案**
- 钱从哪来：云厂商和大厂 capex（阿里/腾讯/字节 capex 上修 → 国产算力芯片、光模块、服务器、PCB、液冷的订单）。
- 卡在哪个环节：先进封装 / 制造产能，以及国产算力芯片的迭代速度。
- 最早感知的数据：北美四大云厂商 capex、英伟达财报指引、光模块龙头季度收入。

**产业链地图**

| 环节 | 代表公司 | 格局 | 为什么重要 |
|---|---|---|---|
| 算力芯片（设计） | 寒武纪、海光信息 | 国产双寡头 | 自主可控核心，ASIC 是合规云厂商选择 |
| 芯片制造/先进封装 | 中芯国际、长电科技 | 瓶颈环节 | 先进封装产能是算力放量的物理约束 |
| 光模块/光芯片 | 中际旭创、新易盛、天孚通信 | 全球领先 | 北美 capex 直接受益，业绩兑现最早 |
| 服务器/PCB | 工业富联、沪电股份、胜宏科技 | 高集中度 | 量最大，跟随算力出货 |
| 液冷/IDC | 英维克、润泽科技 | 渗透率提升 | 功率密度提升的必然配套 |
| 下游应用 | 金山办公、科大讯飞等 | 分散、早期 | token 用量决定需求"第二曲线" |

**仪表盘**
1. 北美四大云厂商 capex（微软/谷歌/Meta/亚马逊季报指引）——全球景气度的锚
2. 国内阿里/腾讯 capex 指引——国产链直接驱动
3. 英伟达财报和指引——全球 AI 芯片供需温度计
4. 光模块龙头季度收入和毛利率——A股兑现最早环节
5. token 用量 / 推理成本下降曲线——应用端需求爆发信号

**当前最大分歧**：推理需求能否接棒训练需求、算力会不会过剩。

**财报精读对象**：寒武纪（国产芯片放量节奏）、中际旭创（北美订单兑现）、工业富联（AI 服务器收入占比）。
