### 首个昇腾950测试基地在北京通州落成

*P1 · ai_semiconductor · catalyst*

**摘要**：昇腾950DT芯片Atlas 850E商用局点落地北京通州，首个昇腾950测试基地同步落成，标志国产高端AI算力从发布走向商用验证阶段，为头部大模型企业、高校与科研院所提供算力支撑，国产算力供给能力与生态适配进入可验证窗口。

**因果链**

- 昇腾950DT芯片与Atlas 850E达成商用条件
- → 首个昇腾950测试基地落成并提供算力支撑
- → 头部大模型企业、高校、科研院所接入测试与适配
- → 国产算力可用性验证与生态适配推进
- → 国内算力采购结构边际变化
- → 配套服务器、光模块、液冷与电力需求传导
- → 相关厂商订单与收入预期变化
- → 估值预期随国产算力叙事强化而调整

**不确定性**

- 本次事件未披露昇腾950测试基地的具体算力规模、芯片出货量、客户接入数量与商用订单金额，无法量化其对收入与利润的实际贡献。
- 昇腾950DT与Atlas 850E的实际性能、软件生态适配度与稳定性缺乏第三方独立验证，商用条件达成不等于大规模客户采用。
- 国产算力采购结构变化受政策、出口管制与云厂商资本开支节奏多重影响，单一测试基地落成难以直接推导行业级需求拐点。

*P1 · ai_semiconductor · policy*

**因果链**

- 特朗普任命克莱顿为AI沙皇，明确反对暂停AI开发
- → 政策信号偏向加速AI发展、放松监管约束
- → 美国AI算力资本开支预期延续甚至上修
- → AI芯片与算力基础设施需求增长
- → 半导体供给紧张或产能扩张
- → 芯片价格与订单能见度变化
- → 算力相关企业收入与利润预期调整
- → 市场对AI算力叙事的估值预期强化

**不确定性**

- 克莱顿的具体职权范围、工作组建议的约束力以及联邦AI采购机制尚不明确，政策对算力需求的量化影响无法评估。

- 本次事件为政策人事信号，短期不直接改变算力供需，传导至半导体订单与收入需经多个中间环节，时滞与衰减程度未知。

### 推理支出2026年首超训练：“Token工厂”崛起 AI基础设施投资逻辑生变

*P1 · ai_semiconductor · catalyst*

**摘要**：信通院报告预计2026年推理算力占AI总负载70.5%，标志AI基础设施投资逻辑从训练主导转向推理与智能体驱动，算力需求结构变化将重塑芯片、网络、存储与电力配套的需求节奏，但报告口径与商业化落地节奏仍需验证。

**因果链**

- 推理与智能体运行负载占比升至70.5%
- → 算力需求从训练一次性开支转向推理持续性运营支出
- → 推理对能效比、内存带宽、时延与单位Token成本敏感度上升
- → 芯片选型与数据中心架构向推理优化倾斜
- → 高速互联、高带宽存储与分布式电力配套需求结构变化
- → 智算集群利用率与Token调用量成为收入核心变量
- → 基础设施投资逻辑从算力规模转向单位Token成本与运营效率
- → 相关环节订单与收入节奏重估，估值锚点可能迁移

**不确定性**

- 信通院报告未披露推理算力占比的统计口径（按负载、按Token量还是按算力时长），不同口径下结论差异可能较大。
- 推理需求增长能否转化为可持续的付费收入尚缺乏公开数据验证，Token调用量的商业化变现效率未知。
- 国产芯片在推理场景的实际性能、生态适配与客户接受度仍处于商用验证早期，份额提升节奏不确定。
