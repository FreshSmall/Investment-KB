## 行业概览
<!-- IAI:SECTION:overview START (v1, 2026-10-17) -->

行业处于从原型展示向小批量制造与多行业部署过渡的早期阶段，**2026上半年全球人形机器人销量3.6万台已超2025全年**，收入前五全为中国企业，中国在整机集成与出口端形成先发优势；但单价偏低、租赁价格持续下行，供给放量快于真实作业需求，行业进入商业化验证期。

- **全球销量翻倍**：2026上半年全球人形机器人销量**3.6万台**、收入**5.4亿美元**，超2025全年；收入前五全为中国企业，**深圳**占两席
- **出口激增**：深圳前8个月机器人出口同比增超**1200%**——基数与品类未披露
- **零部件订单放量**：某智能装备供应商覆盖**80%以上**人形整机厂供应体系，关节模组订单交付加速放量，全产品系列进入半导体前后段设备客户
- **具身智能进产线**：**乐聚智能**与**兆丰股份**联合方案下**15台**人形机器人进入汽车零部件上料常态化运行
- **软银拟收购安保公司**：软银据称考虑以最高**180亿美元**股权估值收购美国最大安保公司**Allied Universal**，作为机器人编队规模化试验场——仍处考虑阶段
- **租赁价格下行**：单日租赁报价从2025年初的**1万-2万元**降至2026年10月的约**3900元**，平台方称价格回归理性
- **Optimus V3设计冻结**：**新剑传动**回复文件披露Optimus V3硬件设计基本冻结、即将进入量产周期——未经特斯拉官方确认
- **端侧AI芯片高增**：**瑞芯微**预告前三季度净利**13.1-13.5亿元**、同比**+68%-73%**，Q3净利环比降**7%-15%**
- **国际标准**：我国牵头制定的全球首个**腿式机器人运动国际标准**获 **ISO** 批准

未披露项：前五名企业名称与单价结构、深圳出口品类与基数、供应商关节模组订单金额与客户结构、乐聚-兆丰股权关系与采购计划、软银交易结构与时间表。

## 供需与价格
<!-- IAI:SECTION:supply_demand START (v1, 2026-10-17) -->

**需求侧**
- **全球销量翻倍**：2026上半年全球人形机器人销量**3.6万台**、收入**5.4亿美元**，超2025全年；收入前五全为中国企业，**深圳**占两席
- **出口激增**：深圳前8个月机器人出口同比增超**1200%**——基数、品类（整机/零部件）与客户类型不明，可持续性存疑
- **零部件订单放量**：某智能装备供应商覆盖**80%以上**人形整机厂供应体系，关节模组订单交付加速放量——订单金额与客户结构未披露
- **具身智能产线需求**：**乐聚智能**与**兆丰股份**联合方案下**15台**人形机器人进入汽车零部件上料常态化运行——单点案例，经济性数据未披露
- **安保场景潜在需求**：软银拟收购**Allied Universal**，将安保服务作为机器人编队规模化试验场——交易尚在考虑阶段，采购模式与规模未知
- **租赁价格下行**：单日报价从**1万-2万元**降至约**3900元**——供给放量快于真实作业需求，需观察降价能否换来订单量与使用时长提升
- **端侧AI芯片需求**：**瑞芯微**端侧AI芯片在机器人、汽车电子、机器视觉、工业等场景放量
- **四足机器人需求**：**Counterpoint** 预测 **2026 年**全球出货量有望**翻倍**，中国企业占近**九成**份额

**供给侧**
- **Optimus V3设计冻结**：**新剑传动**回复文件披露Optimus V3硬件设计基本冻结、即将进入量产周期——供应链定点与模具、产线投入启动，未经特斯拉官方确认
- **关节模组产能**：**万里扬**机器人子公司通过核心客户 **VDA6.3** 标准 **PPAP** 审核，首条关节模组产线具备量产能力
- **特斯拉得州 Optimus 专用产线**主结构接近完工，计划 **2027 年**投产、年产能目标 **1000 万台**——规划口径
- **宇树**发布 **Dex5-S** 灵巧手，**3.99 万元**起，**22 关节**可反向驱动——核心执行部件成本快速下探
- **端侧AI芯片新品**：**瑞芯微** **RK182X**协处理器与**RK3572**进入量产
- PCB 厂商重新报价、光模块厂商锁料——高速光芯片/DSP/mSAP PCB 等关键物料供给偏紧

**价格**
- **租赁价格**：单日报价从**1万-2万元**降至约**3900元**，平台方称已回归理性——全行业出租率与复租率未披露
- **宇树 Dex5-S** 灵巧手 **3.99 万元**起——显著低于此前报价区间，对应配置未披露
- PCB 重新报价、光模块锁料——关键物料价格与交期变化幅度未披露

**技术侧**
- **ISO 腿式机器人运动国际标准**获批——统一测试认证口径，有望降低行业碎片化
- **具身智能场景落地**：乐聚-兆丰汽车零部件上料方案进入常态化运行，验证具身智能在标准化制造场景可行性
- **Figure Helix 2.5** 零样本跨环境泛化，**宇树**、**松延动力**等密集发布具身模型——缺官方技术报告与第三方复现

## 核心风险
<!-- IAI:SECTION:risks START (v1, 2026-10-17) -->

- **租赁价格下行压制收入弹性**：单日租赁报价从**1万-2万元**降至约**3900元**，供给放量快于真实作业需求，租赁运营方回本周期拉长
- **降价与需求因果不明**：租赁价格下行可能是成本下降驱动需求，也可能是供给过剩压制价格，两种情形对产业链利润影响相反
- **销量高增但单价偏低**：2026上半年销量**3.6万台**、收入仅**5.4亿美元**，隐含单价偏低，场景经济性与收入质量未验证
- **出口增速可持续性存疑**：深圳前8个月出口增超**1200%**，但基数、品类（整机/零部件/玩具类）与客户类型不明
- **核心零部件自主化未披露**：人形机器人核心零部件国产化率、单机BOM成本及毛利率数据缺失，利润传导链无法定量验证
- **零部件订单信息不完整**：机构调研未披露供应商名称、关节模组订单金额、客户结构与交付时间表；半导体客户收入贡献与验证周期亦未披露
- **具身智能单点案例经济性未验证**：乐聚-兆丰**15台**机器人常态化运行缺乏稳定性、节拍、维护成本与投资回报数据，股权关系与后续采购计划未披露
- **软银收购高度不确定**：交易仍处"考虑"阶段，无正式要约、交易结构与监管审批细节；机器人替代安保人员的技术成熟度与单位经济模型均无公开数据
- **Optimus V3信息未经官方确认**：设计冻结与量产时间表来自**新剑传动**IPO审核回复文件，未经特斯拉官方确认，量产节奏与规模存在不确定性
- **瑞芯微增长质量待验证**：仅为业绩预告，未披露收入结构、毛利率与各产品线贡献，Q3净利环比降**7%-15%**
- **出货量口径不明**：**IDC** 出货近 **2.5 万台**、**智元**超 **8600 台**，统计口径（是否含科研样机、展示机、政府项目采购）未披露
- **标准到订单时滞**：**ISO** 腿式机器人运动标准获批，但缺乏采用率、认证数量与订单数据
- **关节模组客户未披露**：**万里扬**通过 **PPAP** 审核，但核心客户身份、采购规模、份额分配、产线产能与良率均未披露
- **情绪与基本面背离**：概念股涨幅由情绪与资金驱动，与基本面兑现存在时滞和不确定性
