# 机器人 / 人形机器人

> 系统管理的行业长文档：SECTION 标记内由 AI 节级更新；标记外为人工笔记，永不触碰。

## 行业概览
<!-- IAI:SECTION:overview START (v1, 2026-10-01) -->

行业处于从原型展示向小批量制造与多行业部署过渡的早期阶段，当日新增**头部厂商出货高增**与**存储原厂对物理AI增量市场的前瞻判断**，需求端启动信号增强，但单价、订单结构与利润兑现路径仍缺位。

- **出货量高增**：**IDC** 数据显示 **2026 上半年**全球人形机器人出货近 **2.5 万台**、同比 **+432.1%**，中国出货超 **1.9 万台**、占 **77.9%**
- **头部厂商**：**智元**上半年出货超 **8600 台**，占全球约 **35%**、中国 **45%** 以上，高基数下十倍级增长——统计口径与单价未披露
- **物理AI增量判断**：**美光** CEO 称物理AI（自动驾驶、人形机器人）为数据中心之后下一个存储增量市场，**L4+** 单车内存超 **200GB**、存储达多 **TB**
- **国际标准**：我国牵头制定的全球首个**腿式机器人运动国际标准**获 **ISO** 批准，中国从跟跑到领跑
- **关节模组量产**：**万里扬**机器人子公司通过核心客户 **VDA6.3** 标准 **PPAP** 审核，首条关节模组产线具备量产能力
- **灵巧手新品**：**Sharpa** 在 **IROS2026** 发布三款灵巧手与触觉数据采集产品，指向精细操作与遥操作数据闭环
- **特斯拉Optimus产量爬坡**：报道称近几个月产量提升约 **10 倍**、周产达 **数百台**——基数、版本、良率未披露
- **四足机器人格局**：**Counterpoint** 预测 **2026 年**全球出货量有望**翻倍**，中国企业占近**九成**份额
- **车企入局**：**小鹏**人形机器人自动化产线启用并完成供应链定点，**理想**、**奇瑞**等加码；**东风汽车**称人形机器人**年底小批量试制**

未披露项：IDC/智元出货统计口径与单价、美光物理AI订单与出货数据、ISO标准采用率、万里扬客户身份与订单规模、Sharpa BOM成本与客户验证、Optimus产量基数/良率、小鹏定点范围/份额、车企产线产能与良率。

## 供需与价格
<!-- IAI:SECTION:supply_demand START (v1, 2026-10-01) -->

**需求侧**
- **出货量高增**：**IDC** 数据显示 **2026 上半年**全球人形机器人出货近 **2.5 万台**、同比 **+432.1%**，中国超 **1.9 万台**、占 **77.9%**——产业由技术验证转向商业化落地；单价与订单结构未披露
- **智元出货**：上半年超 **8600 台**，占全球约 **35%**、中国 **45%** 以上，高基数下十倍级增长——多行业部署态落地，统计口径与回款条件未披露
- **物理AI存储需求**：**美光** CEO 提出物理AI为数据中心后下一个存储增量市场，**L4+** 单车内存超 **200GB**、存储多 **TB**，较 **L2+/L3** 高一个数量级——属前瞻指引，缺订单与出货数据
- **特斯拉Optimus产量爬坡**：产量数月提升约 **10 倍**、周产达 **数百台**——带动灵巧手、执行器、减速器、传感器需求预期；基数与良率未披露
- **四足机器人需求**：**Counterpoint** 预测 **2026 年**全球出货量有望**翻倍**，中国企业占近**九成**份额——绝对值与单价未披露
- **小鹏机器人**完成供应链审厂与核心零部件**定点**——执行器、灵巧手、传感器、AI 芯片需求预期前置；份额与单价未披露
- **IFR** 数据显示 **2025 年**全球工业与专业服务人形机器人销量约 **7000 台**——需求真实但基数极小
- 具身智能训练场（"机器人学校"）超 **70 家**启用——数据采集与训练基础设施投入增加；资金来源与采购清单未披露

**供给侧**
- **万里扬关节模组**：子公司通过核心客户 **VDA6.3** 标准 **PPAP** 审核，首条关节模组产线具备量产能力——从样件跨入批量供货门槛；客户身份、订单规模、单价与产能爬坡节奏未披露
- **Sharpa 灵巧手**：**IROS2026** 发布三款灵巧手与触觉数据采集产品——指向触觉传感、微型执行器、轻量化结构件需求；BOM成本、良率与客户验证未披露
- **特斯拉Optimus产线扩张**：产量数月提升约 **10 倍**、周产达 **数百台**——复杂手部、自动化设备与供应商限制仍制约可靠量产；良率与节拍未披露
- **特斯拉得州 Optimus 专用产线**主结构接近完工，计划 **2027 年**投产、年产能目标 **1000 万台**——规划口径，缺节拍/良率/成本与订单验证
- **宇树**发布 **Dex5-S** 灵巧手，**3.99 万元**起，**22 关节**可反向驱动——定价指向核心执行部件成本快速下探；订单与可靠性数据未披露
- **广东具身智能训练场**：注册资本由 **1.62亿** 增至 **3亿**，**越疆**、**风华高科**、**跨维智能**、**自变量机器人**等入股——是否形成实质性订单缺乏披露
- **存储原厂产品结构**：**美光** 提出物理AI增量逻辑，指向车规/工规存储位元需求扩张与产能结构倾斜——尚无订单与长约数据验证
- PCB 厂商重新报价、光模块厂商锁料——高速光芯片/DSP/mSAP PCB 等关键物料供给偏紧

**价格**
- **宇树 Dex5-S** 灵巧手 **3.99 万元**起——显著低于此前报价区间，核心执行部件成本下探；对应配置未披露
- PCB 重新报价、光模块锁料——关键物料价格与交期变化幅度未披露

**技术侧**
- **ISO 腿式机器人运动国际标准**获批——统一测试认证口径，有望降低行业碎片化、加速产品互认；采用率与认证数量未披露
- **Figure Helix 2.5** 零样本跨环境泛化，**宇树**、**松延动力**等密集发布具身模型——缺官方技术报告、成功率与第三方复现

## 核心风险
<!-- IAI:SECTION:risks START (v1, 2026-10-01) -->

- **出货量口径不明**：**IDC** 出货近 **2.5 万台**、**智元**超 **8600 台**，但统计口径（是否含科研样机、展示机、政府项目采购、关联方采购）未披露，台数增长与真实商业收入映射不明确
- **出货高增可持续性**：**智元**为非上市公司，缺乏经审计的收入、毛利与现金流数据；下游付费意愿与复购率无公开数据支撑，多行业部署态落地可持续性存疑
- **物理AI需求未验证**：**美光** CEO 表述属前瞻指引，缺物理AI相关订单、客户、出货量与价格数据；**L4+** 量产时间表与单机存储 BOM 或为上限情景
- **存储需求结构被抵消**：物理AI对存储的拉动可能被手机、PC、传统服务器需求波动抵消，总需求结构变化方向与幅度难以凭单一事件判断
- **标准到订单时滞**：**ISO** 腿式机器人运动标准获批，但缺乏采用率、认证数量与订单数据，标准发布到收入兑现存在时滞
- **灵巧手兑现不确定**：**Sharpa** 产品发布仅基于单一报道，缺乏 BOM 成本、良率、寿命与客户验证数据；**Sharpa** 为非上市公司
- **关节模组客户未披露**：**万里扬**通过 **PPAP** 审核，但核心客户身份、采购规模、份额分配、产线产能与良率均未披露，收入弹性无法判断
- **Optimus产量数据不可验证**：报道称产量提升约 **10 倍**、周产达 **数百台**，但基数、版本与良率未披露，缺第三方交叉验证
- **Optimus量产兑现不确定**：复杂手部、自动化设备与供应商限制仍制约可靠量产；特斯拉量产时间表历史上多次调整
- **四足机器人预测口径不明**：**Counterpoint** 预测 **2026 年**出货翻倍、中国占近**九成**份额，但绝对值、单价与统计口径未披露
- **AI投资与债务融资脆弱性**：AI投资高增长与债务融资脆弱性并存，宏观融资环境变化可能逆转科技公司资本开支节奏
- **训练场股权≠供应链关系**：广东具身智能训练场参股方与训练场之间的交易是否构成关联交易、是否形成实质性订单缺乏披露
- **小鹏定点信息未证实**：供应链审厂与核心零部件定点信息来自消息人士与媒体报道，缺乏公司正式公告与定点合同细节
- **定点→订单转化不确定**：定点仅锁定供应商份额，能否转化为批量订单、收入与利润仍待验证
- **模型发布→订单传导未验证**：具身模型密集发布缺乏实际性能指标、算力消耗与商业化落地数据
- **灵巧手降价兑现不确定**：**Dex5-S** **3.99 万元**起价对应具体配置未披露，能否转化为整机厂批量订单缺乏证据
- **车企布局深度不明**：**理想**、**奇瑞**等布局深度与投入规模缺乏可验证数据；**小鹏**产线产能/良率/单台成本未披露
- **试制到量产周期长**：**东风**"小批量试制"规模、成本、场景未披露，从试制到量产通常需 **12-24 个月**以上验证周期
- **情绪与基本面背离**：概念股涨幅由情绪与资金驱动，与基本面兑现存在时滞和不确定性
